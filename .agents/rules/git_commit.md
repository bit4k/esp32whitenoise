# Rule: Git Commit After Changes

- Führe nach jedem Umbau, Refactoring, Bugfix oder jeder Codeanpassung im Projekt stets einen sauberen Git-Commit (`git commit`) durch.
- Der Commit soll eine prägnante Conventional-Commit-Nachricht tragen (z. B. `feat:`, `fix:`, `chore:`).
- Lass keine abgeschlossenen und kompilierten Änderungen uncommittet im Arbeitsverzeichnis.
