# Agent Rules & Persistent Memory

## Git Commit Workflow (Obligatorisch)
- **Automatische Commits:** Nach JEDEM Umbau, Bugfix, jeder Anpassung oder Code-Änderung MUSS IMMER ein sauberer `git commit` mit einer prägnanten Conventional-Commit-Nachricht (z. B. `fix(...)`, `feat(...)`, `chore(...)`) durchgeführt werden.
- Sobald eine Änderung erfolgreich kompiliert wurde, wird sie unverzüglich committed.
